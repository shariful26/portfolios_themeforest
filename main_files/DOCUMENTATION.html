1 Quick Start Guide

Follow these simple steps to run the template on your computer:

Prerequisites

Ensure you have Node.js (v18 or higher) installed on your system. You can download Node.js from nodejs.org.

Installation Commands

# 1. Unzip the downloaded package and open terminal in frontend folder
cd frontend

# 2. Install all dependencies
npm install

# 3. Start local development server
npm run dev

Open your browser and navigate to http://localhost:3000 to view your live portfolio!

2 100% Zero-Code Customization

All portfolio information, bio, social links, projects, skills, services, experience, testimonials, and blog posts are controlled from a single configuration file:

src/data/portfolio.config.js

Editing Profile Information

export const portfolioData = {
  profile: {
    name: "Your Full Name",
    role: "Senior Full Stack Engineer & Architect",
    headline: "Helping ambitious clients turn ideas into high-impact products.",
    email: "yourname@domain.com",
    phone: "+1 (555) 234-5678",

    avatar: "/path/to/your-photo.jpg",
    resumeUrl: "/assets/resume.pdf",
  },
  // Add your own projects, skills, and experience below...
};

3 Setting Up Live Contact Form Email

The contact form supports both Formspree.io (free form service) and a direct mailto: fallback.

Option A: Formspree Setup (Recommended)

  1. Create a free account at Formspree.io.
  2. Create a new form and copy your Endpoint URL (e.g., https://formspree.io/f/xyzabckz).
  3. Open src/data/portfolio.config.js and update contact.formspreeEndpoint:
contact: {
  formspreeEndpoint: "https://formspree.io/f/YOUR_UNIQUE_ID",
  directEmail: "yourname@domain.com",
}

Option B: Direct Email Fallback

If formspreeEndpoint is left empty, submitting the form will automatically open the visitor's email application with your email address pre-filled!

4 Setting Up Downloadable PDF Resume

  1. Place your PDF file in the public assets folder: public/assets/resume.pdf.
  2. Open src/data/portfolio.config.js.
  3. Update the resumeUrl property:
profile: {
  resumeUrl: "/assets/resume.pdf",
}

Visitors clicking "Download Resume (PDF)" will immediately download your file.

5 Vector Lucide React Icons

All icons throughout the template use lucide-react vector SVG icons. To change or add icons:

import { Award, Code2, Rocket, Heart } from 'lucide-react';

// Render anywhere in your JSX:
<Award className="w-6 h-6 text-amber-500" />

6 Hiding Demo Switcher Bar Before Publishing

To hide the floating Demo Control box at the bottom-right before publishing your live website, edit src/data/portfolio.config.js:

demoSettings: {
  showDemoSwitcher: false, // Set to false for client production build
}

7 Deploying to Production (Vercel / Netlify / Hostinger)

1. Build Production Bundle

npm run build

This creates an optimized dist/ folder ready for deployment.

2. Deploying to Vercel (Free & Instant)

  1. Push your code to GitHub.
  2. Import your repository on Vercel.com.
  3. Framework Preset: Select Vite.
  4. Click Deploy!
